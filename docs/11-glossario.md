# 11 — Glossário

| Termo | Significado |
|---|---|
| AOI | Area of Interest — o terreno que o utilizador define |
| Alteração argilosa | Transformação da rocha em minerais de argila por fluidos, frequentemente associada a mineralização hidrotermal |
| Alteração hidrotermal | Mudança mineralógica causada por fluidos quentes, associada a ouro e cobre |
| Bacia hidrográfica | Área que drena para o mesmo ponto |
| BIF | Banded Iron Formation — formação ferrífera bandada, fonte importante de ferro |
| Canais K, Th, U | Potássio, tório e urânio medidos por radiometria |
| Composto | Imagem única obtida combinando várias datas (mediana) para reduzir nuvens |
| CRS | Sistema de referência de coordenadas |
| Declive | Inclinação do terreno |
| DEM / MDE | Modelo digital de elevação |
| EPSG:32733 | WGS 84 / UTM zona 33S (usado no protótipo de Longonjo) |
| Falha | Fractura da rocha com deslocamento |
| Gossan | Capa de óxidos de ferro sobre um depósito sulfuretado |
| Hillshade | Sombreamento do relevo para realçar formas e estruturas |
| IP | Polarização induzida, método geofísico de campo |
| Landsat | Satélites NASA/USGS, 30 m |
| Lineamento | Feição linear no terreno que pode indicar falha ou fractura |
| Magnetometria | Medição do campo magnético para detectar corpos magnéticos (ex.: ferro) |
| MRDS | Mineral Resources Data System (USGS) |
| NDVI | Índice de vegetação por diferença normalizada |
| NDWI | Índice de água por diferença normalizada |
| OneGeology | Iniciativa internacional de dados geológicos abertos |
| Radiometria | Medição de radiação gama natural das rochas |
| Resistividade | Método geofísico que mede a oposição do solo à corrente eléctrica; útil para água |
| SCL | Scene Classification Layer do Sentinel-2 |
| Sentinel-2 | Satélites Copernicus/ESA, 10–20 m |
| SEV | Sondagem eléctrica vertical |
| SRTM | Shuttle Radar Topography Mission, MDE de ~30 m |
| STAC | Padrão para catálogos de dados geoespaciais |
| SWIR | Infravermelho de onda curta, útil para argila e óxidos |
| Triagem | Avaliação preliminar para decidir onde investir esforço |
| TWI | Topographic Wetness Index — tendência do terreno acumular água |
| UTM | Sistema de coordenadas em metros por zonas |
| Weighted overlay | Sobreposição ponderada de camadas |
